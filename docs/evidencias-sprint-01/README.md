# Evidencias verificables · Sprint 01

Esta carpeta separa las comprobaciones ejecutadas de las capturas que requieren un navegador interactivo. No contiene contraseñas ni datos personales reales.

- [Resumen del sprint](resumen-sprint-01.md): objetivo, alcance, criterios, archivos y límites.
- [Registro de pruebas](pruebas.md): escenarios cubiertos, comandos y resultados observados.
- [Salida original de PHPUnit](phpunit-output.txt): salida sin reconstruir de la última ejecución completa.
- [Verificación HTTP anónima](http-anonimo.txt): códigos de respuesta reales de rutas públicas y protegidas.
- [Estado de Docker](docker-servicios.txt): servicios en ejecución durante la verificación.
- [Guía de capturas](capturas/README.md): diez pantallas exactas para completar con capturas reales.

**Estado de capturas:** pendiente de intervención manual. El navegador Chrome en modo headless de este entorno no pudo iniciar su proceso gráfico y no produjo ninguna imagen. No se incluyen imágenes simuladas.
